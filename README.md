# Mundo Travel

Página web de una agencia de viajes hecha con HTML, CSS, Bootstrap 5 y JavaScript.

## Integrantes

| Integrante | Parte del proyecto |
|---|---|
| Mateo Villarroel | Inicio (`index.html`), estilos (`css/estilos.css`) y JavaScript (`js/script.js`) |
| Cristian Chicaiza | Nosotros (`nosotros.html`) |
| Jorge Otto | Contacto (`contacto.html`) |
| Andrés Moreno | Viajes (`viajes.html`) |

## Funciones

- Buscador de viajes por destino y tipo de viaje.
- Catálogo de paquetes con filtros.
- Lista de viajes seleccionados que se mantiene al cambiar de página (localStorage).
- Formulario de contacto con validación.
- Diseño adaptable a celular, tablet y computadora.

## Cómo abrirlo

Descargar el repositorio y abrir `index.html` en el navegador.
